# Saltmarrow Deep

A gothic roguelike that runs in the browser and installs as an offline app.

Play: https://alemeno-00.github.io/saltmarrow/

## Android app

Download the APK: https://github.com/Alemeno-00/Saltmarrow/releases/latest/download/SaltmarrowDeep.apk

The app shell loads the game from GitHub Pages, so game updates arrive automatically. The APK only needs rebuilding when `android-app/` changes (GitHub Actions does this on push).

Download: https://github.com/alemeno-00/Saltmarrow/releases/download/mac/SaltmarrowDeep.dmg
