# Native sprite animation update

Runtime assets: `assets/flat/actions.webp`, `deaths.webp`, `hero-actions.webp`, `miner-actions.webp`, `corpses.webp`. All five were generated with the built-in image-generation tool using the shipped sprites as identity references, then imported losslessly with nearest-neighbor scaling. Source assets are preserved.

78 new action poses cover all five classes and the five board monsters. Hit reactions interrupt actions; actions follow windup → strike → recovery using the actual attack/cast timing. The miner retains four directional rows. New poses retain a common feet baseline and body scale and bypass the old body rotation/stretch pass.

30 death poses provide six-step collapses for Deep Crawler, Bone Seer, Brine Hag, Rotfiend and Spore Walker. Other core creatures use their current native sprite followed by a newly drawn resting corpse, rather than the old square-sized spin/squash effect. 32 resting corpse sprites cover the core enemy atlas, including Drowned aliases. Hollow Faith keeps its existing authored death sequences. Deaths share the actor depth queue, hide the resting corpse until the collapse completes, and clear on level changes. Fire leaves charred remains. Physical debris uses cached 8×8 fragments from current sprite pixels; elemental effects keep their damage-specific colours and physics.

No gameplay timing, damage, AI, rewards, corpse-interaction rules or simulation coordinates are changed. Cosmetic action tags and corpse appearance metadata are separate from mechanics. Reduced motion uses a static living pose and immediate resting remains.

Validation: timeline and interruption tests; all 78 action/30 death frames and 32 corpse imports; distinct attack phases; collapsed final silhouettes; actual kill/reward/sprite-fragment/level-transition browser checks in full and reduced motion; desktop/mobile movement, doors, picking and combat; existing Drowned/Hollow/death regressions.
