## Build and production files

`node scripts/build-cohesive-biomes.cjs <source-directory>` compiles exclusively from `terrain.png`, `props.png`, and `landmarks.png`. It samples native pixel cells without smoothing, enforces real transparency on isolated objects, and normalizes the 40 cells in each biome to a single 96-color palette.

Production outputs:

- `assets/biomes/sewer-v3.png`
- `assets/biomes/fungal-v3.png`
- `assets/biomes/crypt-v3.png`
- `assets/biomes/mine-v3.png`

Each 512×320 atlas contains 40 reusable 64px cells: 16 complete terrain/architecture cells, 16 functional object/state cells, and eight landmark/biome-specific object cells. Floor render cells remain 32×32. Runtime uses no previous biome atlas and has no old-asset fallback for the four target biomes.
