Supplied image is exact visual reference, reproduce the tall ruined coastal castle in its RIGHTMOST LOWER PANEL, extended naturally into a landscape game title background. Left half dark atmospheric sea and distant cliffs with quiet space for menu text. Match its crisp high-detail PIXEL ART, charcoal and deep desaturated teal, tiny amber windows, deliberate visible pixel clusters and hard edges. No painterly blur, no smooth rendering, no bloom fog covering detail. No text, no logos, no UI, no frames, no characters. Same straight-on slightly overhead environment art style as supplied board.

The supplied `saltmarrow-flat-master.png` is the current visual target. The earlier isometric study is retained on `wip/isometric-reference-study`, not shipped here.

Camera: screen-aligned square tiles, upright actors, row-based foot sorting, low foreground walls. Simulation coordinates, map generation, movement, collision, combat rules, saves and progression remain unchanged. Five existing enemy archetypes receive the reference names and visual skins: rat → Deep Crawler, cultist → Bone Seer, wraith → Brine Hag, ghoul → Rotfiend, shambler → Spore Walker. Their statistics and AI remain unchanged.

All new runtime assets are in `assets/flat/`. Generated assets use the supplied board as an image reference and the built-in image generation tool. They are reference-matched redraws, not pixel-identical extractions. The four portraits are literal lossless source crops. The home scene extends the reference castle into a landscape background. The miner has 16 directional/action frames; the five named monsters have 20 action frames. Other actors use the new atlas with the existing movement, lunge and hit animation system.

Nearest-neighbor import and rendering are used throughout. Town paving retains a small low-contrast palette; no extra floor noise is layered over it. The compact bottom HUD restores explicit numeric stamina and displays a visible combat enemy's real stamina and conditions.
